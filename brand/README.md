# Ellie brand kit

The official visual direction for Ellie. Use it for the web app, the call demo and the slides.

**Start here: open `brand-guide/ellie-brand-guide.html` in a browser.** It has the idea behind the mark, logo rules, colours, type, Ellie's voice, example screens and the build kit. Keep the PNGs next to it.

| Path | What |
|---|---|
| `brand-guide/ellie-brand-guide.html` | The full brand guide |
| `logo/ellie-logo-on-navy.png` | Main logo, 1760 px square on navy `#0E2A3B`. Best for slide title and closing cards |
| `logo/ellie-logo-transparent-for-dark-backgrounds.png` | Transparent. Only on navy or other dark backgrounds |
| `logo/ellie-logo-badge-for-light-backgrounds.png` | Logo on a navy rounded badge. Use on white or light slides |
| `app-icon/` | iOS and Android app icons |
| `web/` | Favicons and PWA icons (copies live in `app/`) |
| `ellie-tokens.css` | Colours and type as CSS variables |
| `README.txt` | The designer's original notes |

## In short

- **Colours:** navy `#0E2A3B` (backgrounds, text, buttons), brass `#C9A24A` (accents), parchment `#F4F1E8` (light backgrounds), seal red `#8E1B12` (scam warnings only). Verdicts: safe `#155C37`, careful `#6E4300` (mark `#E3A21A`), scam `#8E1B12`.
- **Fonts** (Google Fonts): Bricolage Grotesque ExtraBold for headlines and the wordmark, Atkinson Hyperlegible for everything else.
- **Wordmark:** "Ellie" in Bricolage Grotesque ExtraBold with a brass dot on the i.
- **Tagline in the guide:** "Ellie never forgets a scam."
- **Don't:** recolour the ear red or green, flip the elephant to face left, stretch it, add shadows or put it in a frame (except the navy badge).

Where it is used: `app/index.html` (web app) and `app/call-demo/brand/brand.css` (call demo, which maps these tokens onto the demo).
