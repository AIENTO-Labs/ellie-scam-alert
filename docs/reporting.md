# Reporting

Ellie closes the loop after a high-risk call: it alerts the family and prepares a report the user or family can send to the authorities with one tap.

## What a report contains

- Caller number and time
- Claimed identity (e.g. "Berlin Police", "Sparkasse security")
- Tactics detected and the final score
- Transcript extract and recording, if recorded with notice
- What was asked for (codes, transfer, gift cards, cash pickup)
