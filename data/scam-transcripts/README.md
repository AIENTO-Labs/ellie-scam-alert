# Scam transcripts

Sample scam call scripts and typical phrases, used to tune scoring and to write the demo dialogue. Fake or publicly described examples only; no real people, numbers or recordings.

One file per scenario:

- `fake-police.md`: caller claims to be police, says a relative was arrested or a gang targets the user
- `bank-fraud.md`: "security department", account compromised, asks for TAN, transfer to safe account
- `relative-in-trouble.md`: grandchild or child in an accident or arrested, needs money now
- `tax-office.md`: unpaid tax, fine or arrest unless paid today

For each: opening line, tactics used (authority, urgency, secrecy, payment request, credential request, threat), and the phrases that should move the score. Note the source of any phrase you take from a public warning page.
